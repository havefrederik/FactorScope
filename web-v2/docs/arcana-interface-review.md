# Arcana interface observations — 13 October 2026

Reviewed the user's 23-second, 1280 × 720 public product video. Visual observations only; no signed-in access or inference about proprietary calculations.

- Opening portfolio workspace: holdings, numerical summary, factor drill-down and performance remain visible together.
- Optimizer sequence: objectives and portfolio/factor constraints are explicit; the user applies optimization before the comparison appears.
- Comparison sequence: new/old/delta columns appear across holdings, risk and factors. Proposed edits retain the original as context.
- Attribution sequence: local tabs change chart content; grouping changes the holdings table without leaving the workspace.
- Stress sequence: a scenario list sits beside ranked impacts and a selected-scenario breakdown.
- Final sequence: research notes, integrations and idea ranking use the same compact workspace language.

FactorScope implementation priorities: compact controls beside current/proposed allocation; identical-date risk comparisons; stock links; factor exposure comparison; explicit backtest application and applied-settings label; local analytical tabs; all rebalance holdings accessible. Keep existing restrained colours and four-section navigation.

Future work: controlled manual trade editing, saved proposal comparisons, and linked scenario overview/detail. Add factor constraints only when a defensible allocator supports them. Arcana's expected-return objectives, liquidity controls and proprietary factors must not be implied by this prototype.
